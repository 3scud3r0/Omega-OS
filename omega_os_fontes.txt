# Omega OS — núcleo de hardware V1

Kernel experimental x86-64 C99 freestanding, modular, sem libc, heap ou
bibliotecas de driver. Implementa hardware real emulado: Multiboot, MMU,
exceções, VirtIO-Block PCI legacy, persistência por página e SMP em dois vCPUs.
Não é uma certificação de prontidão industrial ou de segurança.

## Build e execução

Pré-requisitos: GCC x86-64, GNU binutils, Make, Python 3 e QEMU x86.
Em Debian: `apt-get install gcc binutils make python3 qemu-system-x86 qemu-utils`.

```sh
make -j2
make run
make test
make test-host
make bundle
```

`make` cria `disk.img` raw de 32 MiB somente se ainda não existir. Usa `qemu-img`
quando disponível, ou truncamento esparso Python com leitura inicial em zeros.
`make clean` preserva `disk.img`. Os testes usam imagens descartáveis em `build/`.

O alvo `run` usa:

```sh
qemu-system-x86_64 -kernel omega_os.elf \
  -drive file=disk.img,if=virtio,format=raw \
  -smp 2 -m 128M -serial stdio -display none
```

Nesta máquina, QEMU foi instalado localmente, sem sudo, de pacotes Debian
verificados. Use `make run QEMU=/workspace/tools/bin/qemu-system-x86_64` e o mesmo
override em `make test`. O diretório de ferramentas não pertence ao repositório.

Validado com GCC 14.2.0, GNU binutils e QEMU 10.0.13/TCG multithread. Pode-se
selecionar cross-toolchain com `CC=x86_64-elf-gcc OBJCOPY=x86_64-elf-objcopy`;
este cross-compiler específico não foi instalado ou validado aqui.

O Makefile mantém `-std=c99 -ffreestanding -nostdlib -O3 -flto -mno-red-zone
-Wall -Wextra -Werror -pedantic`, desabilita builtins e geração de SIMD no kernel.
O cabeçalho Multiboot fica nos primeiros 8 KiB (offset validado pelo teste).
`link.ld` coloca código em 0x100000 e alinha BSS, IDT e DMA em páginas.
O ELF64 intermediário é convertido em contêiner ELF32 pelo objcopy para o
loader Multiboot do QEMU; o código continua x86-64 após o trampolim de 32 bits.

## Memória e persistência

O PMM mantém o limite de 64 MiB e bitmap hierárquico com bit-scan, reservas do
kernel, rejeição de double-free e validação do limite de RAM Multiboot.
A inicialização pressupõe RAM contígua informada por `mem_upper`, como no PC QEMU
validado; não substitui um parser completo de E820 para máquinas arbitrárias.
A MMU também permite mapear MMIO/ACPI abaixo de 4 GiB, com PCD/PWT, e páginas U/S
para o contexto de usuário. DMA usa buffers estáticos identity-mapped em RAM
coerente x86. Há um request em voo, com três descritores de cabeçalho/dados/status.

PCI usa CF8/CFC, varre barramentos, slots e funções, habilita I/O, bus mastering
e desabilita INTx. O driver detecta 1af4:1001 e negocia `VIRTIO_BLK_F_FLUSH`.
Dispositivos somente modernos (1af4:1042) são identificados mas rejeitados com
mensagem explícita: este driver implementa o transporte **legacy**, não modern
PCI capabilities. `virtio_blk_submit` publica DMA assincronamente;
`virtio_blk_poll` consome o used ring. As funções read/write_page esperam a
conclusão com timeout; FLUSH espera a conclusão e exige suporte do dispositivo.

Duas correções importantes ao layout solicitado:

- O tamanho da fila legacy é anunciado pelo dispositivo e não é configurável
  pelo guest. São aceitos tamanhos potência de dois entre 128 e 1024, com arena
  estática de 32 KiB. O QEMU 10 desta validação anuncia 1024, inclusive quando a
  propriedade moderna `queue-size=128` é solicitada. Somente o tamanho anunciado
  é usado; não foi validado um dispositivo que anuncie 128 nesta máquina.
- O available ring fica **imediatamente depois dos descritores**. O used ring é
  alinhado em 4096. Alinhar cada uma das três estruturas separadamente em páginas
  viola o layout legacy para vários tamanhos. A arena contígua começa em 4096.

`mmu_sls_commit` procura dirty bits de hardware nas páginas registradas no SLS.
As páginas transitórias do kernel não são publicadas no disco. Para cada página
registrada, mantém dois slots alternados:

1. Escreve os 4096 bytes do novo estado no slot inativo; aguarda DMA e FLUSH.
2. Escreve uma página de metadados com magic, geração, endereço virtual, CRC64
   dos dados e CRC64 dos metadados; aguarda DMA e outro FLUSH.
3. Só então avança a geração em RAM, limpa PAGE_DIRTY e executa `invlpg`.

No boot/rollback, lê e valida os dois slots, usando a maior geração válida.
Se há metadados não vazios mas nenhum checkpoint válido, falha explicitamente
em vez de reinicializar o estado silenciosamente. Slots da página de índice i
começam nos setores `8 + 32*i` e `24 + 32*i`; cada um tem 8 setores de metadados
seguidos de 8 setores de dados. Registro e ordem dos endereços são fixos.

Isso implementa publicação copy-on-write **por página**; não há um ponteiro raiz
atômico global, transação atômica entre páginas, WAL completo, coletor de lixo,
filesystem, FUA, NVMe ou Ed25519. CRC detecta corrupção acidental, não ataques.
A durabilidade depende de o backend/hardware cumprir FLUSH. Os testes não provam
comportamento sob todos os cortes elétricos, firmwares, corrupção adversarial
ou falhas simultâneas dos dois slots.

## Exceções e fronteira de privilégio

A IDT tem 256 gates de 16 bytes e alinhamento de 4096. Os 32 stubs de exceção
normalizam error codes, salvam todos os GPRs e alinham a pilha antes do handler C.
GDT, TSS, RSP0 e pilha IST de emergência são individuais para BSP/AP.

O contexto de teste entra de fato em CPL3 com `iretq`, CS=0x23, SS=0x1b e IOPL=0.
Somente código e pilha desse contexto têm folhas PAGE_USER. Testes executam:

- Leitura de página supervisor: #PF presente, CR2=0x100000.
- `out dx,al` na COM1: #GP por privilégio de I/O.
- Leitura de CR3: #GP por instrução privilegiada.
- Leitura de página não mapeada: #PF não presente, CR2=0x60000000.

Para #PF/#GP de um contexto de usuário associado a uma tarefa, o handler restaura
o frame do disco, revalida o contrato, põe a tarefa em quarentena e abandona o
contexto violador, devolvendo o controle à pilha salva do kernel. Os testes
corrompem o estado em RAM antes das faltas e verificam a restauração. Exceções
inesperadas no kernel continuam fatais e imprimem vetor, error code, RIP e CR2.

**Os workers produtor/consumidor SMP ainda rodam em Ring 0.** O contexto Ring 3
é o teste da fronteira de hardware e da recuperação, não um runtime completo
de agentes isolados. Não há syscalls, espaços de endereços por processo,
preempção, escalonamento de contextos de usuário, capacidades ou isolamento DMA.
A tag SipHash com chave pública de demonstração continua sendo integridade de
estado; não é autenticação adversarial ou prova Lean.

## SMP

Descobre RSDP por EBDA/BIOS, valida checksums, percorre XSDT ou RSDT e MADT,
incluindo entradas LAPIC e override de endereço. Seleciona um AP habilitado com
ID xAPIC de 8 bits. Mapeia LAPIC sem cache, checa MSR, envia INIT assert/deassert
e dois SIPIs. Delays usam PIT canal 2, sem presumir uma frequência de TSC.

O trampolim copiado para 0x8000 começa em modo real de 16 bits, entra em modo
protegido, carrega CR3 compartilhado, habilita long mode e usa uma pilha própria
estática. O AP carrega sua GDT/TSS/IDT e sinaliza online via release/acquire.

BSP produz 65.536 mensagens enquanto o AP consome exclusivamente o SPSC e
valida seu estado racional. O BSP verifica a conclusão e os IDs APIC distintos.
Depois, o AP fica em HLT e o BSP realiza commits/isolamento. Não há mudança
concorrente de page tables, shootdown TLB remoto ou scheduler SMP geral.
A implementação usa xAPIC MMIO e rejeita x2APIC ativo; não implementa RISC-V.
No QEMU, IDs distintos são vCPUs, não evidência de teste em duas CPUs físicas.

## Testes e evidência

`make test` executa QEMU com `-accel tcg,thread=multi`, verifica Multiboot, UART,
DMA, bytes diretamente na imagem raw pelo host, epochs de ambas as tarefas,
AP online e os faults Ring 3. Encerra QEMU com SIGKILL e verifica recuperação
no reboot. Corrompe o slot mais recente e verifica o fallback para o anterior.

A suíte também usa `-append sls.crash=N` para parar em quatro fronteiras reais:
após DMA de dados, após FLUSH de dados, após DMA de metadados e após FLUSH de
metadados. O hook, inativo por padrão, apenas pausa o guest em HLT; não simula
sucesso de I/O. O host aplica SIGKILL, verifica os slots no arquivo e reinicia.
São cortes nas fronteiras do protocolo, não uma enumeração de todos os instantes
possíveis durante DMA ou da persistência interna de hardware físico.

Logs e imagens de teste ficam em `build/v1-*.log` e `build/v1-*.img`.
`make test-host` verifica 40.000 operações racionais contra frações exatas Python
e 1.000.000 mensagens em duas threads pthread do host. A libc desses testes
não é vinculada ao kernel (`nm -u build/omega64.elf` deve produzir saída vazia).

O kernel termina em HLT depois de validar os subsistemas. Ciclos TSC são
telemetria, não nanossegundos calibrados, previsão térmica ou garantia de latência.
`omega_os_fontes.txt` reúne fontes, headers, linker, Makefile, testes e este README;
regenere com `make bundle` após mudanças.

CFLAGS += -fno-builtin -fno-asynchronous-unwind-tables -fno-unwind-tables -mgeneral-regs-only -MMD -MP
SOURCES = $(wildcard src/*.c)
OBJECTS = $(SOURCES:src/%.c=build/%.o)
.PHONY: all clean run test test-host bundle
all: omega_os.elf disk.img
build:
	mkdir -p $@
build/%.o: src/%.c | build
	$(CC) $(CFLAGS) -c $< -o $@
build/omega64.elf: $(OBJECTS) link.ld
	$(CC) $(CFLAGS) -nostdlib -Wl,-T,link.ld -Wl,--build-id=none -Wl,-z,max-page-size=0x1000 $(OBJECTS) -o $@
# QEMU's Multiboot loader requires an ELF32 container; code switches to long mode.
omega_os.elf: build/omega64.elf
	$(OBJCOPY) -O elf32-i386 $< $@
disk.img:
	@if command -v $(QEMU_IMG) >/dev/null 2>&1; then $(QEMU_IMG) create -f raw $@ 32M; else python3 -c "with open('$@', 'xb') as f: f.truncate(32*1024*1024)"; fi
run: omega_os.elf disk.img
	$(QEMU) -kernel omega_os.elf -drive file=disk.img,if=virtio,format=raw -smp 2 -m 128M -serial stdio -display none
test: omega_os.elf
	python3 tests/v1_validation.py "$(QEMU)"
test-host: | build
	python3 tests/rational_test.py
	$(CC) -std=c99 -O3 -Wall -Wextra -Werror -pedantic -Iinclude -pthread tests/ipc_stress.c src/ipc.c -o build/ipc_stress
	./build/ipc_stress
bundle:
	python3 tests/bundle_sources.py
clean:
	rm -rf build omega_os.elf
-include $(OBJECTS:.o=.d)

OUTPUT_FORMAT(elf64-x86-64)
ENTRY(_start)
PHDRS { code PT_LOAD FLAGS(5); data PT_LOAD FLAGS(6); }
SECTIONS {
 . = 0x100000;
 .multiboot : { KEEP(*(.multiboot)) } :code
 .text : { *(.text.boot) *(.text .text.*) } :code
 .rodata : { *(.rodata .rodata.*) } :code
 . = ALIGN(4096);
 .data : { *(.data .data.*) } :data
 . = ALIGN(4096);
 __bss_start = .;
 .bss (NOLOAD) : {
  *(.bss.boot)
  . = ALIGN(4096); *(.bss.idt)
  . = ALIGN(4096); *(.bss.dma)
  *(.bss .bss.*) *(COMMON)
 } :data
 . = ALIGN(4096);
 __kernel_end = .;
 /DISCARD/ : { *(.eh_frame*) *(.comment) *(.note*) }
}
ASSERT(SIZEOF(.multiboot) == 12, "Multiboot header missing")
ASSERT(__kernel_end < 0x4000000, "Kernel exceeds 64 MiB")

  * replacing that selector with user data in the per-CPU GDT. */

                  "movw $16,%%ax; movw %%ax,%%ds; movw %%ax,%%es; movw %%ax,%%ss"
                  :::"rax","memory");

}

  return 1;

bool ring_push(omega_ring_t *r, uint64_t v) {
 uint64_t h=__atomic_load_n(&r->head,__ATOMIC_RELAXED);
 uint64_t t=__atomic_load_n(&r->tail,__ATOMIC_ACQUIRE);
 if(h-t==RING_CAPACITY) return false;
 r->slots[h&(RING_CAPACITY-1)]=v; __atomic_store_n(&r->head,h+1,__ATOMIC_RELEASE); return true;
}
bool ring_pop(omega_ring_t *r, uint64_t *v) {
 uint64_t t=__atomic_load_n(&r->tail,__ATOMIC_RELAXED);
 uint64_t h=__atomic_load_n(&r->head,__ATOMIC_ACQUIRE);
 if(t==h) return false;
 *v=r->slots[t&(RING_CAPACITY-1)]; __atomic_store_n(&r->tail,t+1,__ATOMIC_RELEASE); return true;
}

static uint64_t summary[4] ALIGN_64;
static uint64_t top;
static uint64_t first_frame,last_frame;
void pmm_init(uint64_t end,uint64_t reserved) {
 uint64_t f;
 memset(free_bits,0,sizeof free_bits); memset(summary,0,sizeof summary); top=0;
 first_frame=(reserved+4095)/4096; last_frame=(end<PHYS_LIMIT?end:PHYS_LIMIT)/4096;
 for(f=first_frame;f<last_frame;f++) { uint64_t w=f/64,s=w/64; free_bits[w]|=1ULL<<(f%64); summary[s]|=1ULL<<(w%64); top|=1ULL<<s; }
}
uint64_t pmm_alloc_frame(void) {
 uint64_t s,w,f;
 if(!top) return 0;
 s=(uint64_t)__builtin_ctzll(top); w=s*64+(uint64_t)__builtin_ctzll(summary[s]);
 f=w*64+(uint64_t)__builtin_ctzll(free_bits[w]); free_bits[w]&=~(1ULL<<(f%64));
 if(!free_bits[w]) { summary[s]&=~(1ULL<<(w%64)); if(!summary[s]) top&=~(1ULL<<s); }
 memset((void *)(f*4096),0,4096); return f*4096;
}
bool pmm_free_frame(uint64_t p) {
 uint64_t f=p/4096,w=f/64,s=w/64;
 if(p%4096||f<first_frame||f>=last_frame||(free_bits[w]&(1ULL<<(f%64)))) return false;
 free_bits[w]|=1ULL<<(f%64); summary[s]|=1ULL<<(w%64); top|=1ULL<<s; return true;
}
bool mmu_map(uint64_t *root,uint64_t va,uint64_t pa,uint64_t flags) {
 uint64_t *t=root; unsigned shift;
 if((va|pa)&4095 || pa>=0x100000000ULL || (va>>47)!=0 || (flags&~(PAGE_PRESENT|PAGE_WRITE|PAGE_USER|PAGE_PWT|PAGE_PCD))) return false;
 for(shift=39;shift>12;shift-=9) { uint64_t *e=&t[(va>>shift)&511];
  if(!(*e&PAGE_PRESENT)) { uint64_t p=pmm_alloc_frame(); if(!p) return false; *e=p|PAGE_PRESENT|PAGE_WRITE; }
  if(*e&128) return false;
  if(flags&PAGE_USER) *e|=PAGE_USER;
  t=(uint64_t *)(*e&MASK);
 }
 t[(va>>12)&511]=pa|flags|PAGE_PRESENT; invlpg(va); return true;
}
static uint64_t scan(uint64_t *t,unsigned level,uint64_t base) {
 unsigned i; uint64_t count=0;
 for(i=0;i<512;i++) { uint64_t e=__atomic_load_n(&t[i],__ATOMIC_RELAXED),va=base|((uint64_t)i<<(12+9*(level-1)));
  if(!(e&PAGE_PRESENT)) continue;
  if(level>1) { if(e&128) panic("unexpected huge page"); count+=scan((uint64_t *)(e&MASK),level-1,va); }
  else if((e&PAGE_DIRTY)&&sls_contains(va)) {
   if(!sls_persist(va,(const void *)(e&MASK))) panic("SLS write/flush failed; dirty retained");
   uart_puts("SLS disk committed page "); uart_put_hex(va); uart_puts("\n");
   __atomic_fetch_and(&t[i],~PAGE_DIRTY,__ATOMIC_ACQ_REL); invlpg(va); count++;
  }
 }
 return count;
}
uint64_t mmu_sls_commit(uint64_t *root) { mfence(); return scan(root,4,0); }

bool mmu_map_device(uint64_t pa,uint64_t length) {
 uint64_t p,end;
 if(!length||pa>=0x100000000ULL||length>0x100000000ULL-pa) return false;
 end=(pa+length+4095)&~4095ULL;
 for(p=pa&~4095ULL;p<end;p+=4096)
  if(p>=PHYS_LIMIT&&!mmu_map(boot_pml4,p,p,PAGE_WRITE|PAGE_PCD|PAGE_PWT)) return false;

}

#include "rational.h"
#define I64_MAX 9223372036854775807LL
#define I64_MIN (-I64_MAX-1)
static uint64_t magnitude(int64_t n) { return n<0?0ULL-(uint64_t)n:(uint64_t)n; }
static uint64_t gcd(uint64_t a,uint64_t b) { while(b) { uint64_t t=a%b; a=b; b=t; } return a; }
bool rational_make(int64_t n,int64_t d,omega_rational_t *r) {
 uint64_t g,un,ud; bool neg;
 if(!d) return false;
 neg=(n<0)!=(d<0); un=magnitude(n); ud=magnitude(d); g=gcd(un,ud); un/=g; ud/=g;
 if(ud>(uint64_t)I64_MAX || un>((uint64_t)I64_MAX+(neg?1ULL:0ULL))) return false;
 r->den=(int64_t)ud;
 r->num=neg?(un==(1ULL<<63)?I64_MIN:-(int64_t)un):(int64_t)un; return true;
}
bool rational_valid(omega_rational_t r) { return r.den>0 && gcd(magnitude(r.num),(uint64_t)r.den)==1; }
/* Checked intermediates: representable results may still be rejected on overflow. */
bool rational_add(omega_rational_t a,omega_rational_t b,omega_rational_t *r) {
 int64_t x,y,n,d; uint64_t g;
 if(!rational_valid(a)||!rational_valid(b)) return false;
 g=gcd((uint64_t)a.den,(uint64_t)b.den);
 if(__builtin_mul_overflow(a.num,b.den/(int64_t)g,&x)||__builtin_mul_overflow(b.num,a.den/(int64_t)g,&y)||__builtin_add_overflow(x,y,&n)||__builtin_mul_overflow(a.den,b.den/(int64_t)g,&d)) return false;
 return rational_make(n,d,r);
}
bool rational_sub(omega_rational_t a,omega_rational_t b,omega_rational_t *r) {
 if(b.num==I64_MIN) return false;
 b.num=-b.num; return rational_add(a,b,r);
}
bool rational_mul(omega_rational_t a,omega_rational_t b,omega_rational_t *r) {
 int64_t n,d; uint64_t g,h;
 if(!rational_valid(a)||!rational_valid(b)) return false;
 g=gcd(magnitude(a.num),(uint64_t)b.den); h=gcd(magnitude(b.num),(uint64_t)a.den);
 if(__builtin_mul_overflow(a.num/(int64_t)g,b.num/(int64_t)h,&n)||__builtin_mul_overflow(a.den/(int64_t)h,b.den/(int64_t)g,&d)) return false;
 return rational_make(n,d,r);
}
/* Continued-fraction comparison avoids cross-product overflow. */
bool rational_cmp(omega_rational_t a,omega_rational_t b,int *result) {
 uint64_t an,bn,ad,bd; int sign=1;
 if(!rational_valid(a)||!rational_valid(b)) return false;
 if((a.num<0)!=(b.num<0)) { *result=a.num<0?-1:1; return true; }
 if(a.num<0) sign=-1;
 an=magnitude(a.num); bn=magnitude(b.num); ad=(uint64_t)a.den; bd=(uint64_t)b.den;
 for(;;) { uint64_t aq=an/ad,bq=bn/bd,ar=an%ad,br=bn%bd;
  if(aq!=bq) { *result=sign*(aq<bq?-1:1); return true; }
  if(!ar||!br) { *result=ar==br?0:sign*(!ar?-1:1); return true; }
  an=ad; ad=ar; bn=bd; bd=br; sign=-sign;
 }
}

/* Per-page, two-slot copy-on-write journal. No disk pointer is trusted without
 * checksums. Data is flushed before publishing metadata; old slot survives.
 * This is NOT a cross-page atomic transaction or cryptographic authentication. */
#define SLS_MAGIC 0x314c53534147454dULL
#define MAX_PAGES 4
static struct { uint64_t va,generation; } pages[MAX_PAGES];
static unsigned page_count;
static unsigned crash_boundary;
void sls_test_crash_after(unsigned boundary) { crash_boundary=boundary; }
static void crash_test_boundary(unsigned boundary) {
 if(crash_boundary!=boundary) return;
 uart_puts("SLS crash-test boundary="); uart_put_dec(boundary); uart_puts("\n");
 /* Deliberate test pause. Host SIGKILL ends the emulator at this I/O boundary. */
 for(;;) __asm__ volatile("cli; hlt");
}
static uint64_t metadata[512] ALIGN_4K;
static uint8_t scratch[4096] ALIGN_4K;
static uint8_t recovered[4096] ALIGN_4K;
static uint64_t crc64(const void *p,size_t n) {
 const uint8_t *b=p; uint64_t crc=0; size_t i; unsigned j;
 for(i=0;i<n;i++) { crc^=(uint64_t)b[i]<<56;
  for(j=0;j<8;j++) crc=(crc<<1)^((crc>>63)?0x42f0e1eba9ea3693ULL:0);
 }
 return crc;
}
static unsigned index_of(uint64_t va) {
 unsigned i; for(i=0;i<page_count;i++) if(pages[i].va==va) return i; return MAX_PAGES;
}
bool sls_contains(uint64_t va) { return index_of(va)!=MAX_PAGES; }
static uint64_t slot_sector(unsigned i,unsigned slot) { return 8ULL+(uint64_t)i*32+(uint64_t)slot*16; }
bool sls_restore(uint64_t va) {
 unsigned i=index_of(va),slot; uint64_t best=0; bool nonempty=false;
 if(i==MAX_PAGES) return false;
 for(slot=0;slot<2;slot++) {
  uint64_t base=slot_sector(i,slot),sum;
  if(!virtio_blk_read_page(base,metadata)) panic("SLS metadata read failed");
  for(unsigned j=0;j<512;j++) if(metadata[j]) nonempty=true;
  sum=metadata[4]; metadata[4]=0;
  if(metadata[0]!=SLS_MAGIC||metadata[2]!=va||!metadata[1]||metadata[1]<=best||crc64(metadata,4096)!=sum) continue;
  if(!virtio_blk_read_page(base+8,scratch)) panic("SLS data read failed");
  if(crc64(scratch,4096)!=metadata[3]) continue;
  best=metadata[1]; memcpy(recovered,scratch,4096);
 }
 if(!best) { if(nonempty) panic("SLS no valid checkpoint; refusing reinitialization"); return false; }
 memcpy((void *)va,recovered,4096); pages[i].generation=best;
 uart_puts("SLS recovered disk generation "); uart_put_dec(best); uart_puts("\n"); return true;
}
bool sls_register(uint64_t va) {
 if((va&4095)||page_count==MAX_PAGES||sls_contains(va)) panic("invalid SLS registration");
 pages[page_count++].va=va; return sls_restore(va);
}
bool sls_persist(uint64_t va,const void *data) {
 unsigned i=index_of(va); uint64_t gen,base;
 if(i==MAX_PAGES||pages[i].generation==~0ULL) return false;
 gen=pages[i].generation+1; base=slot_sector(i,(unsigned)(gen&1));
 /* Source must remain quiescent for this transaction. DMA uses a bounce page. */
 memcpy(scratch,data,4096); memset(metadata,0,4096);
 metadata[0]=SLS_MAGIC; metadata[1]=gen; metadata[2]=va; metadata[3]=crc64(scratch,4096);
 metadata[4]=crc64(metadata,4096);
 if(!virtio_blk_write_page(base+8,scratch)) return false;
 crash_test_boundary(1);
 if(!virtio_blk_flush()) return false;
 crash_test_boundary(2);
 if(!virtio_blk_write_page(base,metadata)) return false;
 crash_test_boundary(3);
 if(!virtio_blk_flush()) return false;
 crash_test_boundary(4);
 pages[i].generation=gen; return true;
}

static uint64_t discover(void) {

 * Padding avail to a page would VIOLATE the legacy queue layout. */
static uint8_t queue_memory[32768] ALIGN_4K __attribute__((section(".bss.dma")));

static vring_avail *available;
static vring_used *used;
static uint16_t queue_size;
static struct { uint32_t type,reserved; uint64_t sector; } request ALIGN_64;
static uint8_t dma_page[4096] ALIGN_4K __attribute__((section(".bss.dma")));
static uint8_t status ALIGN_64;
static uint16_t io,last_used;
static bool inflight,failed,write_operation;
static void *read_target;
static uint64_t capacity;
static bool finish(void) {
 uint64_t start=rdtsc(); bool ok=false;
 while(!virtio_blk_poll(&ok)) {
  if(rdtsc()-start>10000000000ULL) { failed=true; panic("VirtIO timeout: DMA buffers retained"); }
  cpu_pause();
 }

}
void virtio_blk_init(void) {

 if(!d.found) {
  d=pci_find_device(0x1af4,0x1042);
  panic(d.found?"modern-only VirtIO unsupported: use transitional device":"VirtIO PCI device absent");
 }

 outb(io+18,0); outb(io+18,1); outb(io+18,3);
 features=inl(io);
 if(!(features&(1U<<9))) panic("VirtIO FLUSH required for durability");
 outl(io+4,1U<<9); outw(io+14,0);
 queue_size=inw(io+12);
 uart_puts("VirtIO IO="); uart_put_hex(io); uart_puts(" qsize="); uart_put_dec(queue_size); uart_puts(" PFN="); uart_put_hex(inl(io+8)); uart_puts("\n");
 if((queue_size<128||queue_size>1024||(queue_size&(queue_size-1)))||inl(io+8)!=0) panic("VirtIO queue size unsupported");
 memset(queue_memory,0,sizeof queue_memory);
 descriptors=(vring_desc *)queue_memory;
 available=(vring_avail *)(queue_memory+16U*queue_size);
 used=(vring_used *)(queue_memory+((16U*queue_size+6U+2U*queue_size+4095U)&~4095U));
 outl(io+8,(uint32_t)((uint64_t)queue_memory>>12));
 capacity=(uint64_t)inl(io+20)|((uint64_t)inl(io+24)<<32);
 if(capacity<1024) panic("VirtIO disk too small");
 outb(io+18,7);
 if(inb(io+18)&128) panic("VirtIO device rejected initialization");
 uart_puts("PCI VirtIO legacy detected; DMA queue="); uart_put_dec(queue_size); uart_puts("; FLUSH negotiated\n");
}
static bool submit(uint32_t type,uint64_t sector,const void *page) {
 vring_desc *d=descriptors; uint16_t a;
 if(!io||failed||inflight||sector>capacity||capacity-sector<8) return false;
 request.type=type; request.reserved=0; request.sector=sector;
 status=0xff; write_operation=type!=0; read_target=(void *)page;
 if(type==1) memcpy(dma_page,page,4096);
 d[0].addr=(uint64_t)&request; d[0].len=16; d[0].flags=1; d[0].next=type==4?2:1;
 d[1].addr=(uint64_t)dma_page; d[1].len=4096; d[1].flags=(uint16_t)(1|(type==0?2:0)); d[1].next=2;
 d[2].addr=(uint64_t)&status; d[2].len=1; d[2].flags=2; d[2].next=0;
 a=available->idx; ((uint16_t *)((uint8_t *)available+4))[a%queue_size]=0;
 inflight=true;
 __atomic_store_n(&available->idx,(uint16_t)(a+1),__ATOMIC_RELEASE);
 mfence(); outw(io+16,0); return true;
}
bool virtio_blk_submit(uint64_t sector,const void *page,bool write) { return submit(write?1U:0U,sector,page); }
bool virtio_blk_poll(bool *ok) {
 uint16_t u; uint8_t s;
 if(!inflight) { *ok=false; return true; }
 u=__atomic_load_n(&used->idx,__ATOMIC_ACQUIRE);
 if(u==last_used) return false;
 if((uint16_t)(u-last_used)!=1 || ((vring_used_elem *)((uint8_t *)used+4))[last_used%queue_size].id!=0) panic("VirtIO corrupt used ring");
 s=__atomic_load_n(&status,__ATOMIC_ACQUIRE); *ok=s==0;
 if(*ok&&!write_operation) memcpy(read_target,dma_page,4096);
 last_used=u; inflight=false; (void)inb(io+19); return true;
}
bool virtio_blk_write_page(uint64_t sector,const void *page) { return virtio_blk_submit(sector,page,true)&&finish(); }
bool virtio_blk_read_page(uint64_t sector,void *page) { return virtio_blk_submit(sector,page,false)&&finish(); }
bool virtio_blk_flush(void) { return submit(4,0,0)&&finish(); }

"""Cross-check freestanding arithmetic against Python exact fractions."""
import ctypes as C
from fractions import Fraction

                '-std=c99', '-Iinclude', 'src/rational.c', '-o', 'build/rational.so'], check=True)
class R(C.Structure):
    _fields_ = [('num', C.c_longlong), ('den', C.c_longlong)]
lib = C.CDLL('./build/rational.so')
for name in ['add', 'sub', 'mul']:
    f = getattr(lib, 'rational_' + name)
    f.argtypes = [R, R, C.POINTER(R)]
    f.restype = C.c_bool
lib.rational_cmp.argtypes = [R, R, C.POINTER(C.c_int)]
lib.rational_cmp.restype = C.c_bool
rng = random.Random(42)
count = 0
for _ in range(10000):
    a = Fraction(rng.randint(-100000, 100000), rng.randint(1, 100000))
    b = Fraction(rng.randint(-100000, 100000), rng.randint(1, 100000))
    ar, br = R(a.numerator, a.denominator), R(b.numerator, b.denominator)
    for name, expected in [('add', a+b), ('sub', a-b), ('mul', a*b)]:
        out = R()
        assert getattr(lib, 'rational_'+name)(ar, br, C.byref(out))
        assert (out.num, out.den) == (expected.numerator, expected.denominator)
        count += 1
    result = C.c_int()
    assert lib.rational_cmp(ar, br, C.byref(result))
    assert result.value == (a > b) - (a < b)
    count += 1
print(f'PASS: {count} rational operations versus fractions.Fraction')

"""Hardware acceptance: DMA bytes on host, SIGKILL/reboot, CRC fallback, SMP, CPL3."""
import os
from pathlib import Path
import selectors
import shutil
import struct
import subprocess
import sys
import time

QEMU = sys.argv[1] if len(sys.argv) > 1 else 'qemu-system-x86_64'
MASK = (1 << 64) - 1
MAGIC = 0x314C53534147454D
POLY = 0x42F0E1EBA9EA3693

def crc(data):
    value = 0
    for b in data:
        value ^= b << 56
        for _ in range(8):
            value = ((value << 1) ^ (POLY if value >> 63 else 0)) & MASK
    return value

def candidates(image, index):
    result = []
    with open(image, 'rb') as f:
        for slot in range(2):
            sector = 8 + index * 32 + slot * 16
            f.seek(sector * 512)
            meta = bytearray(f.read(4096))
            magic, generation, va, data_crc, header_crc = struct.unpack_from('<5Q', meta)
            meta[32:40] = bytes(8)
            if magic != MAGIC or va != 0x40000000 + index * 4096 or not generation or crc(meta) != header_crc:
                continue
            f.seek((sector + 8) * 512)
            data = f.read(4096)
            if crc(data) == data_crc:
                result.append((generation, sector, data))
    assert result, f'no valid committed slot for page {index}'
    return sorted(result)

def boot(image, label, crash=0):
    cmd = [QEMU, '-kernel', 'omega_os.elf', '-smp', '2', '-m', '128M',
           '-serial', 'stdio', '-display', 'none', '-no-reboot', '-accel', 'tcg,thread=multi']
    cmd += ['-drive', f'file={image},if=virtio,format=raw']
    if crash:
        cmd += ['-append', f'sls.crash={crash}']
    stop = (f'SLS crash-test boundary={crash}\n'.encode() if crash else b'validated; HLT\n')
    process = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.STDOUT)
    captured = bytearray()
    selector = selectors.DefaultSelector()
    selector.register(process.stdout, selectors.EVENT_READ)
    deadline = time.monotonic() + 30
    try:
        while time.monotonic() < deadline and stop not in captured:
            for key, _ in selector.select(0.2):
                chunk = os.read(key.fd, 65536)
                if chunk:
                    captured.extend(chunk)
                    if b'FAIL:' in captured:
                        raise AssertionError(captured.decode(errors='replace'))
                elif process.poll() is not None:
                    raise AssertionError(captured.decode(errors='replace'))
        text = captured.decode(errors='replace')
        assert 'FAIL:' not in text, text
        assert stop in captured, text
        if crash:
            return text
        for marker in ['IDT 256 gates', 'PCI VirtIO legacy detected',
                       'VirtIO disk DMA readback PASS', 'ACPI MADT BSP=',
                       'SMP Core1 online', 'SMP SPSC 65536',
                       'SLS disk committed page', 'vector=14', 'vector=13',
                       'Ring3 PF/GP + disk rollback PASS', 'Ring3 CR3 privilege GP PASS', 'STABLE V1:']:
            assert marker in text, f'{label}: missing {marker}\n{text}'
        return text
    finally:
        process.kill()  # Deliberate SIGKILL, not graceful guest shutdown.
        process.wait(timeout=5)
        selector.close()
        Path(f'build/{label}.log').write_bytes(captured)

offset = binary.find(struct.pack('<I', 0x1BADB002), 0, 8192)

with image.open('r+b') as f:

for boundary in range(1, 5):

/* Hosted test only: kernel objects themselves have no libc dependencies. */
#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
#include "ipc.h"
#define MESSAGES 1000000ULL
static omega_ring_t ring;
static void *produce(void *unused) {
 uint64_t i; (void)unused;
 for(i=0;i<MESSAGES;i++) while(!ring_push(&ring,i)) sched_yield();
 return 0;
}
static void *consume(void *unused) {
 uint64_t i,v; (void)unused;
 for(i=0;i<MESSAGES;i++) {
  while(!ring_pop(&ring,&v)) sched_yield();
  if(v!=i) { fputs("FIFO corruption\n",stderr); exit(1); }
 }
 return 0;
}
int main(void) {
 pthread_t producer,consumer;
 ring_init(&ring);
 if(pthread_create(&producer,0,produce,0)||pthread_create(&consumer,0,consume,0)) return 1;
 if(pthread_join(producer,0)||pthread_join(consumer,0)) return 1;
 puts("PASS: 1000000 SPSC messages between two host threads"); return 0;
}
