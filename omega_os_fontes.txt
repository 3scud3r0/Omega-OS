# Omega-OS

Nanokernel experimental **x86-64**, modular, C99 freestanding, sem libc ou
alocação de heap. A especificação modular final tem precedência sobre o pedido
inicial de arquivo único. Todos os fontes também estão reunidos em
`omega_os_fontes.txt` (`make bundle`).

## Compilar e executar

Pré-requisitos: GCC x86-64, GNU binutils, Make, QEMU x86; Python 3 para testes.
Em Debian: `apt-get install gcc binutils make qemu-system-x86 python3`.

```sh
make -j2
qemu-system-x86_64 -kernel omega_os.elf -serial stdio -display none
make test
make test-host
make bundle
```

Um cross-compiler pode ser selecionado com `make CC=x86_64-elf-gcc
OBJCOPY=x86_64-elf-objcopy`. O build foi validado com GCC 14.2.0 (Debian), LTO,
`-Wall -Wextra -Werror -pedantic`, e QEMU 10.0.13 (TCG).
Não foi validado um cross-compiler `x86_64-elf-gcc` neste ambiente.

No ambiente desta implementação, QEMU foi extraído de pacotes Debian assinados
em `/workspace/tools/qemu` por não haver sudo. Use
`make test QEMU=/workspace/tools/bin/qemu-system-x86_64` e o mesmo override para
`make run`. Essa instalação local é externa ao repositório.

O cabeçalho Multiboot 1 fica no offset 4096, dentro dos primeiros 8 KiB.
`link.ld` organiza um ELF64 intermediário com código carregado em 0x100000.
`objcopy -O elf32-i386` produz o contêiner ELF32 aceito pelo loader Multiboot do
QEMU; não converte as instruções x86-64. `_start` executa código de 32 bits,
zera BSS, instala GDT e quatro níveis de paginação e habilita long mode antes
de chamar C com pilha alinhada de 16 KiB. Compilar somente com `-Ttext`, sem
este script e conversão, não reproduz esse caminho de boot.

## Subsistemas

- UART 16550 COM1: 115200 baud, 8N1, polling; texto, hexadecimal e decimal.
- PMM: limite de 64 MiB, frames de 4096 bytes; bitmap hierárquico de três níveis
  com bit-scan, seleção em tempo constante; reservas até o fim do kernel,
  limite de RAM Multiboot, rejeição de double-free. Executado apenas no BSP.
- MMU: identity mapping de 64 MiB com páginas de 4 KiB e aliases SLS em 1 GiB.
  `mmu_map` aceita endereços inferiores canônicos, páginas dentro dos 64 MiB e
  flags present/write. Frames de page tables são obtidos do PMM. Falta de
  memória pode deixar tabelas intermediárias vazias alocadas; retorna falha.
- SLS experimental: varredura real de PTEs, detecção/limpeza de bit dirty e
  `invlpg`. Checkpoints de tarefas copiam frames completos para frames de RAM.
  Commit e rollback são transações cooperativas de um processador, sem escrita
  concorrente durante a cópia. **Limpar dirty não persiste dados.** Não há SSD,
  NVRAM, journal, recuperação de energia ou atomicidade entre CPUs.
- SPSC: 1024 slots, índices monotônicos unsigned com wrap definido, cache lines
  separadas de 64 bytes, release/acquire. Apenas um produtor e um consumidor;
  inicialização exige exclusividade. Testado também com duas threads no host.
- Racionais: representação reduzida com denominador positivo; operações
  verificam overflow e divisão por zero; comparação usa frações contínuas.
  Overflow intermediário é rejeitado mesmo se o resultado final coubesse.
- Contratos: norma quadrática exata <= 1 e tag SipHash-2-4 dos campos canônicos.
  Corrupção de tag e violação de norma causam restauração do frame e quarentena.
  O checkpoint é revalidado antes do rollback. Uma chave pública fixa de demo
  não fornece autenticação contra um adversário com acesso ao kernel.
  **Não há certificado Lean, verificador de prova formal ou isolamento ring 3.**

## Execução e evidência

O kernel executa 16 ciclos cooperativos de produtor/consumidor no BSP, testa
corrupção e norma inválida e termina em `cli; hlt`. Não inicia APs, não executa
simultaneamente em múltiplos cores, não instala IRQs ou IDT e não tem recuperação
de exceções. Exige CPU x86-64 e firmware compatível com Multiboot; RISC-V não
está implementado. Não há outros serviços ou credenciais para o kernel.

`make test` verifica o cabeçalho no arquivo e inicia de fato o QEMU, captura a
serial em `build/boot.log` e exige que cada teste chegue a PASS e STABLE sem FAIL.
O timeout de 12 s encerra o QEMU, pois o kernel permanece em HLT por projeto.
Uma execução sem mensagens de estabilidade falha no teste.

`make test-host` compara 40.000 operações racionais com `fractions.Fraction`
e transfere 1.000.000 mensagens ordenadas entre duas threads pthread. A libc
nesses testes pertence exclusivamente ao host. O kernel não tem símbolos
externos pendentes (`nm -u build/omega64.elf` não produz saída).

Trecho observado na validação:

```text
[OMEGA-OS] BOOT x86-64 / 4-level paging
TEST rational arithmetic/overflow PASS
TEST SPSC full/empty/FIFO/wrap PASS
SLS dirty 0x0000000040000000 checkpoint tracking (RAM)
SLS dirty 0x0000000040001000 checkpoint tracking (RAM)
IPC transferred 16 messages; contracts accepted
IMMUNE quarantine + full frame rollback id=2
IMMUNE quarantine + full frame rollback id=1
TEST contract/tag/norm/quarantine/frame rollback PASS
CPU TSC cycles: 27930136
STABLE: 16 cooperative cycles completed; RAM checkpoints only; entering HLT
```

Ciclos de TSC variam por execução e incluem logs seriais. Não são necessariamente
ciclos efetivos do core; não são convertidos em nanossegundos sem calibração.
Não existe baseline anterior para alegar ausência de regressão de latência.
Previsões sobre tempos de boot, taxas de branch miss, consumo, desgaste,
convergência cognitiva ou meses de operação não foram medidas nem são garantidas.

#include "ipc.h"
typedef char head_tail_separate[(__builtin_offsetof(omega_ring_t,tail)==64)?1:-1];
void ring_init(omega_ring_t *r) { r->head=0; r->tail=0; }
bool ring_push(omega_ring_t *r, uint64_t v) {
 uint64_t h=__atomic_load_n(&r->head,__ATOMIC_RELAXED);
 uint64_t t=__atomic_load_n(&r->tail,__ATOMIC_ACQUIRE);
 if(h-t==RING_CAPACITY) return false;
 r->slots[h&(RING_CAPACITY-1)]=v; __atomic_store_n(&r->head,h+1,__ATOMIC_RELEASE); return true;
}
bool ring_pop(omega_ring_t *r, uint64_t *v) {
 uint64_t t=__atomic_load_n(&r->tail,__ATOMIC_RELAXED);
 uint64_t h=__atomic_load_n(&r->head,__ATOMIC_ACQUIRE);
 if(t==h) return false;
 *v=r->slots[t&(RING_CAPACITY-1)]; __atomic_store_n(&r->tail,t+1,__ATOMIC_RELEASE); return true;
}

static void rational_tests(void) {
 omega_rational_t a,b,r; int c;
 require(rational_make(2,-4,&a)&&a.num==-1&&a.den==2,"normalize");
 require(rational_make(1,3,&b),"rational create");
 require(rational_add(a,b,&r)&&r.num==-1&&r.den==6,"rational add");
 require(rational_sub(a,b,&r)&&r.num==-5&&r.den==6,"rational sub");
 require(rational_mul(a,b,&r)&&r.num==-1&&r.den==6,"rational mul");

static void ring_tests(void) {
 uint64_t v; unsigned i;
 ring_init(&channel); require(!ring_pop(&channel,&v),"empty ring");
 /* Exercise full capacity and several wraps of slot indices. */
 for(unsigned round=0;round<3;round++) {
  for(i=0;i<RING_CAPACITY;i++) require(ring_push(&channel,i),"ring fill");
  require(!ring_push(&channel,0),"ring full");
  for(i=0;i<RING_CAPACITY;i++) require(ring_pop(&channel,&v)&&v==i,"FIFO");
 }
 channel.head=~0ULL-511; channel.tail=channel.head;
 for(i=0;i<1024;i++) { require(ring_push(&channel,i),"counter wrap push"); require(ring_pop(&channel,&v)&&v==i,"counter wrap pop"); }
 ring_init(&channel); uart_puts("TEST SPSC full/empty/FIFO/wrap PASS\n");
}

void kmain(uint32_t magic,uint32_t info) __attribute__((used,externally_visible));
void kmain(uint32_t magic,uint32_t info) {
 uint64_t phys[4],cycles,start,dirty,value; unsigned i,step;
 omega_task_t *tasks[2],*saved[2]; uint64_t available;
 uart_init(); uart_puts("[OMEGA-OS] BOOT x86-64 / 4-level paging\n");
 require(magic==0x2badb002,"Multiboot magic");
 require(info<PHYS_LIMIT-12,"Multiboot pointer");
 { const uint32_t *mb=(const uint32_t *)(uint64_t)info;
  require((mb[0]&1)!=0,"Multiboot memory information"); available=0x100000ULL+(uint64_t)mb[2]*1024;
 }
 /* Everything at/below kernel end is reserved. Boot info is consumed above. */
 pmm_init(available,(uint64_t)__kernel_end); uart_puts("PMM 64 MiB cap initialized\n");
 for(i=0;i<4;i++) { phys[i]=pmm_alloc_frame(); require(phys[i]!=0,"PMM allocation"); uart_puts("PMM allocated "); uart_put_hex(phys[i]); uart_puts("\n"); }
 { uint64_t f=pmm_alloc_frame(); require(f&&pmm_free_frame(f)&&!pmm_free_frame(f),"frame free/double-free"); require(pmm_alloc_frame()==f,"frame reuse"); require(pmm_free_frame(f),"frame release"); }
 require(!pmm_free_frame(0)&&!pmm_free_frame(PHYS_LIMIT),"PMM reserved bounds");
 for(i=0;i<2;i++) {
  uint64_t va=0x40000000ULL+(uint64_t)i*4096;
  require(mmu_map(boot_pml4,va,phys[i],PAGE_WRITE),"map SLS task");
  tasks[i]=(omega_task_t *)va; saved[i]=(omega_task_t *)phys[2+i];
  init_task(tasks[i],i+1); require(omega_checkpoint(tasks[i],saved[i]),"initial checkpoint");
 }
 rational_tests(); ring_tests();
 start=rdtsc();
 /* Cooperative producer/consumer on BSP: no AP startup is claimed. */
 for(step=0;step<16;step++) {
  require(omega_admit(tasks[0],saved[0]),"producer admission");
  require(rational_make((int64_t)(step%4),8,&tasks[0]->state[0]),"producer state");
  tasks[0]->epoch++; tasks[0]->proof_hash=omega_contract_token(tasks[0]);
  require(omega_admit(tasks[0],saved[0]),"producer contract");
  require(ring_push(&channel,step),"producer send");
  require(omega_admit(tasks[1],saved[1]),"consumer admission");
  require(ring_pop(&channel,&value)&&value==step,"consumer receive");
  require(rational_make((int64_t)(value%4),8,&tasks[1]->state[0]),"consumer state");
  tasks[1]->epoch++; tasks[1]->proof_hash=omega_contract_token(tasks[1]);
  require(omega_admit(tasks[1],saved[1]),"consumer contract");
  for(i=0;i<2;i++) require(omega_checkpoint(tasks[i],saved[i]),"commit checkpoint");
  dirty=mmu_sls_commit(boot_pml4); require(dirty>=2,"hardware dirty tracking");
 }
 cycles=rdtsc()-start;
 uart_puts("IPC transferred 16 messages; contracts accepted\n");
 /* Corruption injection must restore the entire frame, then quarantine. */
 tasks[1]->state[0].num=99;
 require(!omega_admit(tasks[1],saved[1])&&tasks[1]->quarantined,"quarantine");
 require(tasks[1]->state[0].num==saved[1]->state[0].num,"rollback value");
 require(!omega_verify_contract(tasks[1]),"quarantined admission");
 /* Valid tag does not authorize an invalid norm. */
 tasks[0]->state[0].num=2; tasks[0]->state[0].den=1;
 tasks[0]->proof_hash=omega_contract_token(tasks[0]);
 require(!omega_admit(tasks[0],saved[0]),"norm violation");
 uart_puts("TEST contract/tag/norm/quarantine/frame rollback PASS\nCPU TSC cycles: "); uart_put_dec(cycles);
 uart_puts("\nSTABLE: 16 cooperative cycles completed; RAM checkpoints only; entering HLT\n");
 for(;;) __asm__ volatile("cli; hlt");
}

#include "mmu.h"
#include "uart.h"
#define MASK 0x000ffffffffff000ULL
static uint64_t free_bits[256] ALIGN_64;
static uint64_t summary[4] ALIGN_64;
static uint64_t top;
static uint64_t first_frame,last_frame;
void pmm_init(uint64_t end,uint64_t reserved) {
 uint64_t f;
 memset(free_bits,0,sizeof free_bits); memset(summary,0,sizeof summary); top=0;
 first_frame=(reserved+4095)/4096; last_frame=(end<PHYS_LIMIT?end:PHYS_LIMIT)/4096;
 for(f=first_frame;f<last_frame;f++) { uint64_t w=f/64,s=w/64; free_bits[w]|=1ULL<<(f%64); summary[s]|=1ULL<<(w%64); top|=1ULL<<s; }
}
uint64_t pmm_alloc_frame(void) {
 uint64_t s,w,f;
 if(!top) return 0;
 s=(uint64_t)__builtin_ctzll(top); w=s*64+(uint64_t)__builtin_ctzll(summary[s]);
 f=w*64+(uint64_t)__builtin_ctzll(free_bits[w]); free_bits[w]&=~(1ULL<<(f%64));
 if(!free_bits[w]) { summary[s]&=~(1ULL<<(w%64)); if(!summary[s]) top&=~(1ULL<<s); }
 memset((void *)(f*4096),0,4096); return f*4096;
}

 if(p%4096||f<first_frame||f>=last_frame||(free_bits[w]&(1ULL<<(f%64)))) return false;
 free_bits[w]|=1ULL<<(f%64); summary[s]|=1ULL<<(w%64); top|=1ULL<<s; return true;
}
bool mmu_map(uint64_t *root,uint64_t va,uint64_t pa,uint64_t flags) {
 uint64_t *t=root; unsigned shift;
 if((va|pa)&4095 || pa>=PHYS_LIMIT || (va>>47)!=0 || (flags&~(PAGE_PRESENT|PAGE_WRITE))) return false;
 for(shift=39;shift>12;shift-=9) { uint64_t *e=&t[(va>>shift)&511];
  if(!(*e&PAGE_PRESENT)) { uint64_t p=pmm_alloc_frame(); if(!p) return false; *e=p|PAGE_PRESENT|PAGE_WRITE; }
  if(*e&128) return false;
  t=(uint64_t *)(*e&MASK);
 }

}
static uint64_t scan(uint64_t *t,unsigned level,uint64_t base) {

 for(i=0;i<512;i++) { uint64_t e=__atomic_load_n(&t[i],__ATOMIC_RELAXED),va=base|((uint64_t)i<<(12+9*(level-1)));
  if(!(e&PAGE_PRESENT)) continue;
  if(level>1) { if(e&128) panic("unexpected huge page"); count+=scan((uint64_t *)(e&MASK),level-1,va); }
  else if(e&PAGE_DIRTY) { uart_puts("SLS dirty "); uart_put_hex(va); uart_puts(" checkpoint tracking (RAM)\n");
   __atomic_fetch_and(&t[i],~PAGE_DIRTY,__ATOMIC_ACQ_REL); invlpg(va); count++;
  }
 }
 return count;
}

/* SipHash-2-4 over canonical fields; integrity tag, NOT a Lean proof or
 * adversarial isolation: the fixed demo key is public inside this kernel. */
static uint64_t rot(uint64_t x,unsigned n) { return (x<<n)|(x>>(64-n)); }
static void round_sip(uint64_t v[4]) {
 v[0]+=v[1]; v[1]=rot(v[1],13); v[1]^=v[0]; v[0]=rot(v[0],32);
 v[2]+=v[3]; v[3]=rot(v[3],16); v[3]^=v[2]; v[0]+=v[3];
 v[3]=rot(v[3],21); v[3]^=v[0]; v[2]+=v[1]; v[1]=rot(v[1],17); v[1]^=v[2]; v[2]=rot(v[2],32);
}
uint64_t omega_contract_token(const omega_task_t *t) {
 uint64_t v[4]={0x736f6d6570736575ULL^0x0706050403020100ULL,0x646f72616e646f6dULL^0x0f0e0d0c0b0a0908ULL,0x6c7967656e657261ULL^0x0706050403020100ULL,0x7465646279746573ULL^0x0f0e0d0c0b0a0908ULL};
 uint64_t words[11]; unsigned i;
 words[0]=t->id; words[1]=t->epoch;
 for(i=0;i<STATE_DIM;i++) { words[2+2*i]=(uint64_t)t->state[i].num; words[3+2*i]=(uint64_t)t->state[i].den; }
 words[10]=80ULL<<56;
 for(i=0;i<11;i++) { v[3]^=words[i]; round_sip(v); round_sip(v); v[0]^=words[i]; }
 v[2]^=255; for(i=0;i<4;i++) round_sip(v); return v[0]^v[1]^v[2]^v[3];
}
bool omega_verify_contract(const omega_task_t *t) {
 omega_rational_t norm={0,1},sq; omega_rational_t one={1,1}; unsigned i; int cmp;
 if(t->quarantined||!t->id||t->proof_hash!=omega_contract_token(t)) return false;
 for(i=0;i<STATE_DIM;i++) {
  if(!rational_mul(t->state[i],t->state[i],&sq)||!rational_add(norm,sq,&norm)) return false;
 }
 return rational_cmp(norm,one,&cmp)&&cmp<=0;
}
bool omega_checkpoint(omega_task_t *t,omega_task_t *checkpoint) {

 /* Both pointers refer to dedicated, page-sized physical frames. */

}
bool omega_admit(omega_task_t *t,const omega_task_t *checkpoint) {

}

#include "rational.h"
#define I64_MAX 9223372036854775807LL
#define I64_MIN (-I64_MAX-1)
static uint64_t magnitude(int64_t n) { return n<0?0ULL-(uint64_t)n:(uint64_t)n; }
static uint64_t gcd(uint64_t a,uint64_t b) { while(b) { uint64_t t=a%b; a=b; b=t; } return a; }
bool rational_make(int64_t n,int64_t d,omega_rational_t *r) {
 uint64_t g,un,ud; bool neg;
 if(!d) return false;
 neg=(n<0)!=(d<0); un=magnitude(n); ud=magnitude(d); g=gcd(un,ud); un/=g; ud/=g;
 if(ud>(uint64_t)I64_MAX || un>((uint64_t)I64_MAX+(neg?1ULL:0ULL))) return false;
 r->den=(int64_t)ud;
 r->num=neg?(un==(1ULL<<63)?I64_MIN:-(int64_t)un):(int64_t)un; return true;
}
bool rational_valid(omega_rational_t r) { return r.den>0 && gcd(magnitude(r.num),(uint64_t)r.den)==1; }
/* Checked intermediates: representable results may still be rejected on overflow. */
bool rational_add(omega_rational_t a,omega_rational_t b,omega_rational_t *r) {
 int64_t x,y,n,d; uint64_t g;
 if(!rational_valid(a)||!rational_valid(b)) return false;
 g=gcd((uint64_t)a.den,(uint64_t)b.den);
 if(__builtin_mul_overflow(a.num,b.den/(int64_t)g,&x)||__builtin_mul_overflow(b.num,a.den/(int64_t)g,&y)||__builtin_add_overflow(x,y,&n)||__builtin_mul_overflow(a.den,b.den/(int64_t)g,&d)) return false;
 return rational_make(n,d,r);
}
bool rational_sub(omega_rational_t a,omega_rational_t b,omega_rational_t *r) {
 if(b.num==I64_MIN) return false;
 b.num=-b.num; return rational_add(a,b,r);
}
bool rational_mul(omega_rational_t a,omega_rational_t b,omega_rational_t *r) {
 int64_t n,d; uint64_t g,h;
 if(!rational_valid(a)||!rational_valid(b)) return false;
 g=gcd(magnitude(a.num),(uint64_t)b.den); h=gcd(magnitude(b.num),(uint64_t)a.den);
 if(__builtin_mul_overflow(a.num/(int64_t)g,b.num/(int64_t)h,&n)||__builtin_mul_overflow(a.den/(int64_t)h,b.den/(int64_t)g,&d)) return false;
 return rational_make(n,d,r);
}
/* Continued-fraction comparison avoids cross-product overflow. */
bool rational_cmp(omega_rational_t a,omega_rational_t b,int *result) {
 uint64_t an,bn,ad,bd; int sign=1;
 if(!rational_valid(a)||!rational_valid(b)) return false;
 if((a.num<0)!=(b.num<0)) { *result=a.num<0?-1:1; return true; }
 if(a.num<0) sign=-1;
 an=magnitude(a.num); bn=magnitude(b.num); ad=(uint64_t)a.den; bd=(uint64_t)b.den;
 for(;;) { uint64_t aq=an/ad,bq=bn/bd,ar=an%ad,br=bn%bd;
  if(aq!=bq) { *result=sign*(aq<bq?-1:1); return true; }
  if(!ar||!br) { *result=ar==br?0:sign*(!ar?-1:1); return true; }
  an=ad; ad=ar; bn=bd; bd=br; sign=-sign;
 }
}

       '-kernel', 'omega_os.elf', '-serial', 'stdio', '-display', 'none',
       '-no-reboot', '-m', '128M']

    output, _ = proc.communicate(timeout=3)

"""Cross-check freestanding arithmetic against Python exact fractions."""
import ctypes as C
from fractions import Fraction
import random
import subprocess

subprocess.run(['gcc', '-shared', '-fPIC', '-O3', '-Wall', '-Wextra', '-Werror',
                '-std=c99', '-Iinclude', 'src/rational.c', '-o', 'build/rational.so'], check=True)
class R(C.Structure):
    _fields_ = [('num', C.c_longlong), ('den', C.c_longlong)]
lib = C.CDLL('./build/rational.so')
for name in ['add', 'sub', 'mul']:
    f = getattr(lib, 'rational_' + name)
    f.argtypes = [R, R, C.POINTER(R)]
    f.restype = C.c_bool
lib.rational_cmp.argtypes = [R, R, C.POINTER(C.c_int)]
lib.rational_cmp.restype = C.c_bool
rng = random.Random(42)
count = 0
for _ in range(10000):
    a = Fraction(rng.randint(-100000, 100000), rng.randint(1, 100000))
    b = Fraction(rng.randint(-100000, 100000), rng.randint(1, 100000))
    ar, br = R(a.numerator, a.denominator), R(b.numerator, b.denominator)
    for name, expected in [('add', a+b), ('sub', a-b), ('mul', a*b)]:
        out = R()
        assert getattr(lib, 'rational_'+name)(ar, br, C.byref(out))
        assert (out.num, out.den) == (expected.numerator, expected.denominator)
        count += 1
    result = C.c_int()
    assert lib.rational_cmp(ar, br, C.byref(result))
    assert result.value == (a > b) - (a < b)
    count += 1
print(f'PASS: {count} rational operations versus fractions.Fraction')

/* Hosted test only: kernel objects themselves have no libc dependencies. */
#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
#include "ipc.h"
#define MESSAGES 1000000ULL
static omega_ring_t ring;
static void *produce(void *unused) {
 uint64_t i; (void)unused;
 for(i=0;i<MESSAGES;i++) while(!ring_push(&ring,i)) sched_yield();
 return 0;
}
static void *consume(void *unused) {
 uint64_t i,v; (void)unused;
 for(i=0;i<MESSAGES;i++) {
  while(!ring_pop(&ring,&v)) sched_yield();
  if(v!=i) { fputs("FIFO corruption\n",stderr); exit(1); }
 }
 return 0;
}
int main(void) {
 pthread_t producer,consumer;
 ring_init(&ring);
 if(pthread_create(&producer,0,produce,0)||pthread_create(&consumer,0,consume,0)) return 1;
 if(pthread_join(producer,0)||pthread_join(consumer,0)) return 1;
 puts("PASS: 1000000 SPSC messages between two host threads"); return 0;
}
